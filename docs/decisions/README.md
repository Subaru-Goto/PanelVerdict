# The decision record

Closed tickets from the file-based Wayfinder tracker era (2026-07 → 2026-08-21). Each
file is a resolved ticket whose body carries the question, the argument, and the
resolution — the project's ADRs in ticket form. **Read before re-arguing anything**; a
decision lives in exactly one place, its ticket.

Live work moved to **GitHub Issues** on 2026-08-21 (ticket 082). The map is
[#122 · Map: PanelVerdict next chapter](https://github.com/Subaru-Goto/PanelVerdict/issues/122);
tickets are its sub-issues, titled with their pre-migration id ("067 · …").

The two closed maps in this directory — `000-map.md` (v1) and `055-map-public-demo.md`
(public demo) — hold the *Decisions so far* indexes for their eras.
